This project leverages the free 2500 tokens provided by the serper API to provide you with 100 images of your choice each call. This repo is made to provide a simple file that completes an action - not to invent something brand new.

## Additional Information
Serper provides each account 2500 tokens to use. Each token allows for 10 images however selecting 100 images only uses 2 tokens and thus providing more for less. This simple script allows you to send a request of whatever image type you like and get the image results in that channel. Please note that this is only a showcase of a script. I recommend simply hosting off of VSC as it will be the easiest for you. The only files not included are the node_modules and the .env however those can be easily setup!

```.env
DISCORD_TOKEN=ABC123
CLIENT_ID=ABC123
SERPER_API_KEY=ABC123
```
