This project leverages the free 2500 tokens provided by the serper API to provide you with 100 images of your choice each call. 

## Additional Information
Serper provides each account 2500 tokens to use. Each token allows for 10 images however selecting 100 images only uses 2 tokens and thus providing more for less. This simple script allows you to send a request of whatever image type you like and get the image results in that channel. Please note that this is only a showcase of a script.
